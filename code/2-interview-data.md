# Робота з даними у JavaScript і TypeScript
---
### Типи даних
JavaScript має 7 примітивних типів і 1 непримітивний (reference type): `string`, `number`, `boolean`, `undefined`, `null`, `symbol`, `bigint`, `object`.

У TypeScript є всі типи JavaScript, а також власні типи, які існують лише під час компіляції: `any`, `unknown`, `never`, `void`, `enum`, `tuples`, `union types`, `intersection types`, `literal types`, `type aliases`, ` interface`.

---
### Object 

**Об'єкт (Object)** — це колекція пар ключ → значення. Ключі — це властивості (properties), а значення можуть бути будь-якого типу: число, рядок, масив, функція або інший об'єкт.

JavaScript
```
const user = {
    id: 1,
    name: "John",
    active: true
};
```

TypeScript
```
type User = { //можна також визначати через interface
    id: number;
    name: string;
    active: boolean;
};
```

### Array
Масив (`Array`) — це впорядкована колекція елементів. Кожен елемент має індекс, який починається з 0. У JavaScript масив може містити значення різних типів, але в TypeScript зазвичай використовують масиви одного типу.

**Найпоширеніші методи масивів:**
* `push()` -	додати в кінець
* `pop()` -	видалити останній
* `shift()` -	видалити перший
* `unshift()` -	додати на початок
* `map()` - створити новий масив
* `filter()` -	відфільтрувати
* `find()` -	знайти перший елемент
* `reduce()` -	звести масив до одного значення
* `some()` -	хоча б один підходить
* `every()` -	усі підходять
* `includes()` -	перевірити наявність
* `sort()` -	сортування
---

### `map()`
**`map()`** — це метод масиву, який створює новий масив, застосовуючи передану функцію до кожного елемента початкового масиву.
```
const numbers = [1, 2, 3, 4];
const result = numbers.map(number => number * number); //[1, 4, 9, 16]
```

**`map()`** vs **`forEach()`**: `map()` - створює новий масив, `forEach()` - просто виконує дію для кожного елемента.

---

### `filter()`

**`filter()`** -це метод масиву, який повертає новий масив із елементами, для яких callback-функція повернула true.

Основні характеристики:
* не змінює оригінальний масив;
* може повернути менше елементів, ніж було;
* повертає завжди масив.

```
const numbers = [1, 2, 3, 4, 5];
const evenNumbers = numbers.filter(number => number % 2 === 0);     //[2, 4]
```

**`map()`** vs **`filter()`**: `map()` - використовується для трансформації, `filter()` - використовується для відбору.

**`filter()`** vs **`find()`**: `filter()` - повертає масив, `find()` - повертає перший знайдений елемент.

---

### `find()`

**`find()`** — це метод масиву, який повертає перший елемент, що задовольняє задану умову.

---

### reduce() 

**`reduce()`** — це метод масиву, який проходить по всіх елементах масиву та накопичує результат в одному значенні за допомогою акумулятора (accumulator).
Основні характеристики: 
* не змінює оригінальний масив;
* повертає одне значення;
* може повертати будь-який тип;
* використовується для агрегації та обчислень.
```
const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, number) => acc + number, 0);   //10
```
