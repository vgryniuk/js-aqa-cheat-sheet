### == vs === 

Оператори `==` і `===` в JavaScript використовуються для порівняння значень, але вони мають різні принципи роботи:

* **== (loose equality, не строгий оператор рівності):**
        `==` перевіряє рівність двох значень, при цьому виконується приведення типів для порівняння. Наприклад, `5 == '5'` поверне `true`, оскільки значення після приведення типів будуть однаковими.
* **=== (Strict equality, строгий оператор рівності, також відомий як оператор ідентичності):**
        `===` також порівнює значення, але без приведення типів. Порівняння відбувається за значенням і типом. Це означає, що обидва операнди повинні бути одного і того ж типу, а потім порівнюються значення. Наприклад, `5 === '5'` поверне `false`, оскільки типи операндів відрізняються.

У TS використовують `===`

### Truthy і Falsy
* **Truthy** — значення, яке при перетворенні на `boolean` дає `true`.
* **Falsy** — значення, яке при перетворенні на `boolean` дає `false`.

У JavaScript існує лише 8 falsy значень:
```
false
0
-0
0n
""
null
undefined
NaN
```
Все інше — truthy, зокрема `" ", [], {}`.

### var vs let vs const
**`var`**
* Якщо змінні оголошені через `var` в середині функції, вони мають функціональну область видимості (function scope), що означає, що вони доступні лише всередині функції, у якій були оголошені (включаючи блоки коду).
* Якщо змінна була оголошена через `var` за межами будь-якої функції, вона буде глобальною змінною. Оголошення var поза будь-якою функцією робить цю змінну доступною в усьому файлі (якщо це модуль Node.js) або на рівні глобальної області видимості (якщо це браузерний JavaScript). Це може призвести до проблем з масштабованістю програми через можливість конфліктів імен змінних.
* Змінні `var` можуть бути переоголошені та переназначені, іншими словами, їхні значення можна змінювати після оголошення.

```
function test() {
    if (true) {
        var value = 10;
    }

    console.log(value);
}

test(); \\10 бо var має function scope
```

**`let`**
* `let` використовує блочну область видимості (block scope), тобто змінні, оголошені з використанням `let`, видимі лише всередині блока, у якому вони оголошені (блок - це частина коду, закрита у фігурні дужки {}).
* Змінні `let` також можуть бути переназначені, але не можуть бути знову оголошені у тому ж самому блоку.

**`const`**
* `const` також має блочну область видимості і працює так само, як `let` в цьому аспекті. Відмінність полягає у тому, що змінні, оголошені за допомогою `const`, повинні бути ініціалізовані при оголошенні, і після цього їхнє значення не можна змінити. Це означає, що `const` створює константу, значення якої залишається незмінним протягом життєвого циклу змінної.

### Scope

* **Global scope** — змінна доступна всюди.
* **Function scope** — змінна доступна тільки всередині функції.
* **Block scope** — змінна доступна тільки всередині блоку `{}`.

`var` має function scope.

`let` і `const` мають block scope.

### any vs unknown у TypeScript
* **any** → вимикає перевірку типів
* **unknown** → змушує перевірити тип перед використанням
```
let value: any = "hello";

value.toUpperCase(); // OK
value.test();        // OK
value.foo.bar();     // OK
```

```
let value: unknown = "hello";

if (typeof value === "string") {
    value.toUpperCase();
}
```

### interface vs type
* **interface** — описує структуру об'єкта (контракт).
* **type** — створює будь-який тип: об'єкти, union, primitive, tuple тощо.
```
interface User {
  name: string;
  age: number;
}

type Status = "success" | "error";
```
Interface використовує `extends`
```
interface User {
    id: number;
    name: string;
}

interface Admin extends User {
    permissions: string[];
}
```

Type використовує  `intersection (&)`
```
type User = {
    id: number;
    name: string;
};

type Admin = User & {
    permissions: string[];
};
```

### null vs undefined?

* **undefined** - означає, що змінна була оголошена, але значення ще не присвоєне. Значення відсутнє автоматично.
* **null** - означає, що розробник явно встановив відсутність значення. **Значення відсутнє навмисно**.

```
null == undefined // true
null === undefined // false
```

### Hoisting
**Hoisting** — це механізм JavaScript, при якому оголошення змінних і функцій обробляються перед виконанням коду. Простими словами, JavaScript спочатку "піднімає" (hoist) оголошення, а вже потім виконує код. Важливо розуміти, що піднімається оголошення, але не завжди значення.

* **function declaration** - повністю hoisted;
* **var** - hoisted, але отримує значення 'undefined';
* **let і const** - hoisted, але знаходяться в **Temporal Dead Zone (TDZ)**, тому використовувати їх до оголошення не можна.

```
console.log(name);
var name = "John"; // undefined
```
```
console.log(name);
let name = "John"; // ReferenceError
```

```
login(); // Login

function login() {
    console.log("Login");
}
```
